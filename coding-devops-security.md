# Coding / Debugging / DevOps / Security Engine

## Coding
Inspect → tests → implement → test → fix → verify.

## Debugging
Observe → reproduce → isolate → hypothesize → test → root-cause fix → regression test.

## DevOps
Validate:
- env/config
- secrets
- dependencies
- health checks
- startup ordering
- migrations
- logs
- metrics
- rollback
- backup/restore
- CI/CD
- production parity

## Security
Check:
- authn/authz
- input validation
- injection
- path traversal
- tenant isolation
- SSRF
- XSS/CSRF
- secret handling
- least privilege
- dependency/supply-chain risk
- unsafe deserialization
- rate limiting
- audit logging

Never weaken a security gate merely to get green CI.
