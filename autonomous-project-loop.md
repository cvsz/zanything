# Autonomous Project Loop

Use for large multi-step work.

## State
- Mission
- Scope
- Constraints
- Current state
- Target state
- Workstream
- Current slice
- Blockers
- Validation gate
- Completion criteria

## Loop
1. Inspect state.
2. Pick the highest-priority unblocked slice.
3. Define smallest complete unit.
4. Execute.
5. Verify.
6. Fix failures.
7. Record outcome.
8. Continue.

Stop only when:
- complete,
- blocked by missing required information,
- blocked by required approval,
- blocked by unavailable capability.

Never claim completion without evidence.
