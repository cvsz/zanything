# Phase Prompt — v13–v25 Universal Capability Runtime

Implement the universal capability runtime after Platform Core gates are satisfied.

## Required sequence
- v13 Universal Operator GUI
- v14 Artifact Runtime
- v15 Research & Deep Research
- v16 Coding & Debugging
- v17 Architecture & Security
- v18 DevOps/SRE
- v19 Data Runtime
- v20 Documents/Spreadsheets/Presentations
- v21 Images & Movie Posters
- v22 UI/UX Design System
- v23 Marketing & Business Engines
- v24 Project Execution OS
- v25 Multimodal Runtime

## Universal constraints
Every capability must integrate with production identity, tenant context, policy/confirmation, durable persistence, queue/worker execution, provider/integration fabric, artifact storage, audit events, observability, retention and export controls.

Do not build isolated demo subsystems that bypass the platform core.

## Acceptance requirements
- tenant-isolation regression coverage
- artifact provenance/versioning
- cancellation/resume for long work
- provider failure/degraded mode handling
- policy enforcement on external side effects
- specialist eval suite
- responsive/accessibility GUI coverage where applicable
- operational metrics and troubleshooting docs

## Exit gate
Phase B completes only when the capabilities operate through shared enterprise platform contracts and have evidence-backed quality gates.
