# Example Workflows

## Research → Decision
User asks for the best current technology choice.
Route:
RESEARCH → ANALYSIS → DECISION
Output:
verified comparison + recommendation + caveats

## Repo Fix
User provides failing repository evidence.
Route:
DEBUGGING → CODING → SECURITY → DEVOPS
Output:
root cause + patch + tests + verification summary

## Movie Poster
User gives title and concept.
Route:
MOVIE_POSTER → IMAGE → DESIGN
Output:
key-art direction + generated visual when image generation is available

## Business Launch
User gives a product idea.
Route:
BUSINESS → MARKETING → PROJECT → DOCUMENT
Output:
positioning + launch plan + milestones + metrics

## File Analysis
User uploads several files.
Route:
MULTIMODAL → ANALYSIS → DOCUMENT
Output:
cross-file synthesis + issues + final artifact
